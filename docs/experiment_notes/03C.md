# 03C 直接序列扩频与 RAKE 接收

## 实验目的

用 5 级 m 序列实现直接序列扩频（DS-SS）的扩频与解扩，观察伪随机码的自相关/互相关性质；在多径信道上实现 RAKE 接收机，把可分辨的多径分量按码片对齐后相干合并，验证 RAKE 用码域分集对抗多径衰落的机理；进一步比较 m 序列与随机码、不同扩频因子、单用户与多用户（多址干扰）条件下的差异。

## 方法与参数

**扩频码**：5 级线性反馈移位寄存器（本原多项式 $x^5+x^3+1$——即 $x^5+x^2+1$ 的互反形式，两者产生同一 m 序列族的不同相位；反馈抽头 `[0,1,0,0,1]`），周期 $2^5-1=31$，一个信息比特对应 31 个码片，处理增益 $10\lg 31=14.91$ dB。

**信道与接收**：三径等功率信道（时延 0/1/2 码片，增益按 $\sum|h_p|^2=1$ 归一化）+ AWGN；RAKE 用三个指峰分别对齐三条径，按估计的信道增益做等增益合并（EGC）或最大比合并（MRC），单指接收机只取第一条径做相干检测。

**评价口径**：扩频不改变每比特的 $E_b/N_0$，因此 AWGN 下扩频前后的 BER 曲线应重合；扩频的收益只体现在多址隔离度与多径分集上。

| 参数 | 取值 |
| --- | --- |
| 扩频码 | 5 级 m 序列，周期 31；对照：长度 31 的随机码池 |
| 扩频因子 | 1 / 7 / 31 / 63（扫描） |
| 调制 | BPSK（$E_s=1$） |
| 多径信道 | 3 径等功率，时延 0/1/2 码片，$\sum|h_p|^2=1$ |
| 合并方式 | 单指（无 RAKE）、3 指 EGC、3 指 MRC |
| Eb/N0 网格 | AWGN 0:2:10 dB；多径 3:3:21 dB；CDMA 0:2:10 dB |
| 每点样本 | AWGN 1000 块 × 100 bit = 1.0×10⁵ bit；多径与 CDMA 2000 块 × 100 bit = 2.0×10⁵ bit；码对比自适应到每点 ≥400 个误码（21 dB 用 1.1×10⁸ bit） |
| 随机种子 | 42（`set_seed` 同时复位 torch、numpy 与 sionna 的随机源），连跑三次 8 个 CSV 哈希一致 |

## 分析

AWGN 链路的误码率与 BPSK 理论曲线吻合：0 dB 处仿真 7.842×10⁻² 对理论 7.865×10⁻²（−0.3%），4 dB 处 1.271×10⁻² 对 1.250×10⁻²（+1.7%），说明扩频/解扩与能量归一化没有引入额外损失；扫描扩频因子时 SF=1/7/31/63 的四条曲线在 0~8 dB 内绝对差不超过 1.9×10⁻³（相对 2.5%），印证"按每信息比特归一化后扩频不改变误码率"这一基本结论——扩频的收益不在单用户 AWGN 中，而在多址隔离与多径分集。

多径下差距立即显现：三径等功率、单指接收时 3 dB 处误码率 1.823×10⁻¹（理论 1.840×10⁻¹），曲线斜率约 1 阶；改用 3 指 RAKE-EGC 后降到 5.868×10⁻²，MRC 进一步降到 4.734×10⁻²，与 3 阶分集的理论值 4.637×10⁻² 吻合。以 BER = 10⁻² 为门槛，单指需要 18.61 dB，EGC 只需 7.64 dB（增益 10.97 dB），MRC 只需 6.87 dB（增益 11.75 dB）；21 dB 处单指仍有 5.43×10⁻³ 的误码（该点单指的 1 阶理论值为 5.85×10⁻³，实测低 2.5$\sigma$ 属抽样偶然；用 4×10⁶ bit/点复核，单指在 18/21/24 dB 反而比 1 阶理论高 10.9%/22.6%/47.8%，并收敛到约 1.2×10⁻³ 的残余 ISI 平台——单指漏掉的两径经 m 码旁瓣 −1/31 形成 $-(h_1+h_2)/31$$ 串扰，在 |h₀| 深衰落时翻转判决，所以单指曲线在 12 dB 以上不能用纯 1 阶理论对照），而两种 RAKE 在 2×10⁵ bit 内已无错误。这一增益（10.97/11.75 dB）并不是 14.91 dB 的处理增益本身带来的：处理增益只把码片域的信噪比整体抬高，宽带噪声同比例放大，单用户每比特信噪比并不改变；真正起作用的是三条路径提供的 3 阶多径分集（曲线斜率由 1 阶变 3 阶）。RAKE 的关键不是"扩频把噪声摊薄"，而是把 3 条可分辨径变成 3 阶分集。

m 序列的价值体现在相关特性上：$\tau\neq0$ 时自相关恒为 $-1/31$（−0.0323），而随机码在 ±1、±15 处分别为 −0.1613、−0.2903；两条 m 序列的互相关为 3/31（20.28 dB 隔离度）；随机码池的峰值副瓣中位数 0.3548（最坏 0.6129），而 m 序列与 400 条随机码的互相关绝对值最大 0.4839（中位 0.0968）——相对 m 序列自身旁瓣 0.0323，隔离度约 23.5 dB。把这两条性质搬到多径链路（表 5）：3 dB 起 m 序列已不劣于随机码，9~12 dB 优势最大（分别低 8% 与 17%），21 dB 处差距 16%，即在同等条件下旁瓣可控的伪随机码能把误码率压低一到两成。

多用户 CDMA 的结果给出扩频的另一面：加入一个使用另一条 m 序列、带独立载波相位的干扰用户后，0 dB 处误码率仅由 7.882×10⁻² 升到 7.905×10⁻²，6 dB 处由 2.510×10⁻³ 升到 2.860×10⁻³；但用户数继续增加时，多址干扰累积，6 dB 处 K = 1/2/4/8/16 的误码率依次为 2.39×10⁻³ / 3.57×10⁻³ / 5.43×10⁻³ / 1.478×10⁻² / 3.174×10⁻²，K = 16 时比单用户恶化 13 倍。这说明扩频系统的容量是"隔离度换用户数"：正交码的互相关决定本底干扰，用户数决定干扰累积的斜率。

## 实现与调试要点

- **单指接收漏相位补偿**：最早直接对解扩结果取实部，三径下 BER 恒为 0.5；改为 $\mathrm{Re}(h_0^{*} z_0)$ 相干检测后与 1 阶理论线吻合。定位方法是用"单径 AWGN"做单元自检，BER 应精确等于 BPSK 理论值。
- **模板断言的统计稳定性**：m 序列与随机码在 12~21 dB 的 BER 只差 2%~18%，2×10⁵ bit 时误码仅几十个，比值抖动超过 5% 容差会导致 `np.all(m<=1.05*rand)` 随机失败。先做 2×10⁷~6×10⁷ bit 大样本探针确认真实关系（18 dB 比值 1.060、21 dB 1.179），再把对比实验改成"每点累计 ≥400 误码"的自适应样本量 + 共随机数配对，三次运行稳定通过。
- **多用户扫描的相位语义**：给目标用户也乘随机载波相位时，所有 K 的 BER 都是 0.5；改为目标用户相位同步、仅干扰用户随机相位后，K=1 恰好等于 AWGN 理论值 2.388×10⁻³，多址干扰随 K 单调增长，判别逻辑才自洽。

## 结论

1. 5 级 m 序列（周期 31）含 15 个 +1 与 16 个 −1，周期自相关旁瓣恒为 −1/31，两条 m 序列互相关 3/31（20.28 dB）；处理增益 10lg31 = 14.91 dB；直扩/解扩在无噪条件下比特往返错误 0/4000，与 BPSK 理论曲线的偏差 ≤1.7%。
2. 三径等功率信道下，单指接收的误码率随 Eb/N0 仅按 1 阶下降；3 指 RAKE 把它变成 3 阶分集，BER = 10⁻² 所需的 Eb/N0 从 18.61 dB 降到 7.64 dB（EGC）与 6.87 dB（MRC），相对增益 10.97 dB 与 11.75 dB，实测分集阶数与理论一致。
3. 扩频因子 1→63 的扫描表明，在按每比特能量归一化的口径下 AWGN 误码率几乎不变（0 dB 处四条曲线绝对差 ≤1.9×10⁻³，相对 2.5%），扩频的收益应理解为多址隔离度与多径分集；m 序列相对随机码的旁瓣优势（峰值 0.0323 对 0.3548，相差 20.8 dB）在 RAKE 链路中转化为 2%~17% 的误码率优势；多用户下 6 dB 处 K 从 1 增到 16 使 BER 恶化 13 倍。
