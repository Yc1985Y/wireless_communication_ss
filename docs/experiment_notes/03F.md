# 03F 深度学习神经接收机

## 实验目的

用一个小型全连接网络完全替代 QPSK 的 LLR 判决器：输入接收符号的 I/Q 分量与噪声功率，直接输出两个比特的后验 logits，验证"从数据中学到的判决规则"能否达到与理论 MAP 判决、Sionna APP Demapper 相同的误码性能。在此基础上进一步考察混合信噪比训练相对固定信噪比训练的泛化能力、网络学到的判决区域与理想 MAP 判决的吻合程度，以及神经网络接收机的推理开销。

## 方法与参数

**链路**：随机比特 → Gray 映射 QPSK（Sionna `Constellation("qam", 2)`，平均符号能量 $E_s=1$）→ AWGN 信道（`sionna.phy.channel.AWGN`，复噪声方差 $N_0$）→ 神经接收机 → 硬判决；理论曲线取 Gray 码 QPSK 的 $P_b=\frac12\operatorname{erfc}\sqrt{\gamma_b}$。训练时每个样本是一帧 128 个 QPSK 符号，噪声在 0~10 dB 的 $E_b/N_0$ 上均匀采样（混合训练），损失函数为逐比特 `BCEWithLogitsLoss`。

**网络结构**

| 层 | 尺寸 | 激活 |
| --- | --- | --- |
| 输入层 | 3（$\mathrm{Re}(y)$、$\mathrm{Im}(y)$、$\log_{10}N_0$） | — |
| 全连接 1 | $3\times32$ | ReLU |
| 全连接 2 | $32\times32$ | ReLU |
| 输出层 | $32\times2$（bit0、bit1 的 logits） | — |
| 可训练参数 | 1250 个 | — |

**训练与评估超参数**

| 项目 | 设置 |
| --- | --- |
| 优化器 / 学习率 | Adam / $10^{-3}$ |
| batch | 512 帧 × 128 符号 = 65536 符号/步 |
| 训练步数 | 主模型 2500 步（混合 0~10 dB）；对照模型 2000 步（固定 6 dB） |
| 训练耗时 | 混合训练约 54~69 s、固定训练约 47~50 s（单机 CPU 8 线程，随同机负载波动） |
| 随机种子 | torch / numpy / sionna 均 42；训练数据生成器独立 seed = 1234 |
| 可复现性 | 两次独立执行后 6 个 CSV 中 5 个（BER、损失、泛化、判决一致率）sha256 逐字节一致；仅含实测耗时的 `03F_complexity.csv` 随机器负载变化 |
| BER 评估 | 每个 $E_b/N_0$ 点 2 × 8192 × 128 符号（$4.19\times10^{6}$ bit）累计误码；基线为 Sionna APP Demapper 硬判决 |

| --- | --- |

| --- | --- | --- | --- |
| 神经接收机 | 1250 | 0.072 s | 1184 |
| Sionna APP Demapper（通用实现） | 0 | 0.078 s | — |
| QPSK 闭式 LLR（同任务解析实现） | 0 | $8.4\times10^{-4}$ s | 约 6 |

## 分析

0~8 dB 内神经接收机的 BER 与理论最大相差 5.3%（8 dB：2.010e-4 对 1.909e-4），与 Sionna APP Demapper 的绝对差最大 1.11×10⁻⁴（4 dB 处，相对 0.9%），其余点不超过 3.3×10⁻⁵，说明网络学到的是近似 MAP 的判决规则而不是记住训练集；10 dB 处 5.48e-6 对理论 3.87e-6，点估计的 $E_b/N_0$ 代价为 0.15 dB，但该点 4.19×10⁶ bit 按理论只有约 16 个期望错误、实测 23 个，误码数的 95% 置信区间对应代价为 [−0.05, +0.32] dB、泊松检验 p=0.13；因此正确表述是“与解析 LLR 在统计误差内等价（≤0.3 dB，95% CI）”，而不是“实现了 0.15 dB 的确定性代价”。训练损失从 0.6997 降到 0.0461，与 $E_b/N_0\approx4.5\sim5$ dB 处的理论比特熵（0.036~0.050）同量级。固定 6 dB 训练的模型在 10 dB 只损失 0.11 dB，判决区域与理想 MAP 的比特重合率达 99.66%/99.58%（6 dB），可见网络学到的是与噪声功率无关的几何判决，额外输入 $\log_{10}N_0$ 主要用来校准判决置信度。复杂度上，1250 参数的网络每符号 1184 次乘加，1e6 符号推理 0.072 s 对 Demapper 的 0.078 s，两者同量级。

## 结论

在 QPSK + AWGN 场景下，3-32-32-2 的 1250 参数神经接收机仅用混合信噪比训练 2500 步（CPU 约 1 分钟），即在 0~8 dB 内复现了理论 QPSK 的误比特率曲线，并在 10 dB 的有限样本统计下与之等价（等效代价 0.15 dB）；其判决区域在 $\pm2.2$ 网格上与理想 MAP 的边界几何重合率为 98.7%~99.8%（按符号分布加权的失配仅 $3.75\times10^{-6}$），推理开销与 Sionna 通用 Demapper 同量级（0.072 s 对 0.078 s，$10^6$ 符号），但比同任务的闭式 LLR 慢约 87 倍。实验表明数据驱动的接收机可以在简单信道上替代解析 LLR 计算，而混合信噪比训练并不是获得泛化性的必要条件——网络学到的是判决几何而非某个特定噪声水平的映射。
