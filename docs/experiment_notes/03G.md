# 03G 脉冲成形与匹配滤波：RRC 滚降因子与无 ISI 传输

## 实验目的

1. 从公式出发独立实现根升余弦（RRC）成形滤波器，并在时域/频域与 Sionna 的 `RootRaisedCosineFilter` 逐点比对，验证实现正确性。
2. 构建 16-QAM 基带链路的完整"上采样 + RRC 成形 → AWGN → 匹配滤波 + 符号速率抽样"流程，用符号间隔上的过零点检验无 ISI 条件。
3. 定量考察滚降因子 $\beta$ 对峰均比（PAPR）、占用带宽、残余 ISI 与 BER 的影响，给出"带宽-功率效率"折中的实验依据；并比较有/无匹配滤波、不同抽样相位偏差下的性能损失。

## 方法与参数

**RRC 时域表达式。** 取符号周期 $T=1$、过采样 $T_s=T/N_{ss}$，根升余弦脉冲为

$$
h(t)=\frac{1}{T}\cdot\frac{\sin\!\left[\pi t(1-\beta)\right]+4\beta t\cos\!\left[\pi t(1+\beta)\right]}{\pi t\left[1-(4\beta t)^2\right]},
$$

其中奇异点 $t=\pm T/(4\beta)$ 处取极限值

$$
h\!\left(\pm\frac{T}{4\beta}\right)=\frac{\beta}{T\sqrt{2}}\left[\left(1+\frac{2}{\pi}\right)\sin\!\left(\frac{\pi}{4\beta}\right)+\left(1-\frac{2}{\pi}\right)\cos\!\left(\frac{\pi}{4\beta}\right)\right],
$$

$\beta\to0$ 时退化为理想低通 $\mathrm{sinc}(t/T)$（带宽 $1/2T$）。发射端为 $x(t)=\sum_k a_k h(t-kT)$（上采样后卷积），接收端用同一 $h(t)$ 匹配滤波，级联响应为升余弦（RC）脉冲：

$$
p(t)=h(t)*h(-t),\qquad p(kT)=\delta[k]\ \ (\text{无 ISI 条件}),
$$

因此抽样判决无 ISI，理论误码率就是 16-QAM 在加性白高斯噪声下的 $P_b=\frac{3}{8}\operatorname{erfc}\sqrt{\frac{2}{5}\cdot\frac{E_b}{N_0}}$。滤波器系数按 $\sum_n h^2[n]=1$ 归一化，使级联增益为 1、AWGN 方差可直接由 $N_0$ 设定。核心卷积用 `torch.nn.functional.conv1d` 对 I/Q 两路分别实现（不调用 Sionna 的滤波算子），并与 Sionna 的 `padding="full"` 输出逐点比对；成形后截取第 $L/2$ 个样点起的 $N\cdot N_{ss}$ 点以补偿 $(L-1)/2$ 的群时延。

**指标定义。** 峰均比 $\mathrm{PAPR}=10\log_{10}\left(\max|x|^2/\overline{|x|^2}\right)$；占用带宽取 Welch 功率谱（单边、`nperseg=2048`）下降到峰值 $-30$ dB 处的宽度并除以符号率；残余 ISI 取内部符号重构误差 $|y_k-a_k|$ 的均方根。

**参数表**

| 参数 | 取值 |
| --- | --- |
| 调制方式 | 16-QAM（`QAMSource(4)`） |
| 过采样倍数 $N_{ss}$ | 8（模板单元用 4） |
| RRC 截断跨度 span | 10 个符号（模板单元 12） |
| 滤波器抽头数 $L$ | $10\times8+1=81$ |

| 模板链路规模 | 8 批 × 128 符号 |

| 定时偏差扫描 | 0 / 1 / 2 / 3 / 4 个样点（0~0.5 符号），$E_b/N_0=12$ dB |
| 随机种子 | `torch.manual_seed(42)`、`np.random.seed(42)`、`sionna.phy.config.seed=42` |

## 分析

实验结果给出"带宽效率"与"实现代价"的清晰折中。其一，RRC 自主实现与 Sionna 的最大偏差仅 $2.0\times10^{-8}\sim4.9\times10^{-8}$，说明在奇异点 $t=\pm T/(4\beta)$ 处正确取极限是公式实现的关键；级联 RC 在符号间隔处的旁瓣由 $\beta=0.15$ 的 $2.25\times10^{-2}$（$-32.9$ dB）降至 $\beta=0.8$ 的 $3.95\times10^{-4}$（$-68.1$ dB），残差来自 span=10 截断而非公式误差。其二，$\beta$ 增大使占用带宽由 1.29 升到 1.76 倍符号率（理论 $1+\beta=1.15\sim1.80$），但残余 ISI rms 从 $3.62\times10^{-2}$ 降到 $6.83\times10^{-4}$、PAPR 落到 5.2 dB 平台，即 $\beta$ 越大越"功率友好、定时宽松"：1/8 符号偏差下 $\beta=0.15$ 的 BER 为 $2.59\times10^{-2}$，$\beta=0.8$ 仅 $2.24\times10^{-3}$。其三，BER 层面四个 $\beta$ 在 4~12 dB 内都紧贴无 ISI 理论（10 dB 处 $1.72\sim2.22\times10^{-3}$ 对理论 $1.75\times10^{-3}$），而取消匹配滤波（补 AGC 归一化后）同一 SNR 的 BER 恶化到 0.1123（61 倍），直接印证匹配滤波把噪声带宽压到符号率窄带这一核心作用：理想 16-QAM 在 10 dB 的 BER 仅 $1.75\times10^{-3}$，未滤波时带内噪声功率被放大 8.24 dB，相当于把工作点拉回约 1.8 dB。

## 结论

1. 按公式独立实现的 RRC 滤波器与 Sionna 参考实现一致到单精度舍入量级（$\le4.9\times10^{-8}$），级联 RC 脉冲在符号间隔处满足无 ISI 条件（span=10 时最差旁瓣 $-32.9$ dB）。
2. 上采样 + RRC 成形 + 匹配滤波 + 符号速率抽样的链路 BER 与 16-QAM 无 ISI 理论吻合（$E_b/N_0=4\sim12$ dB 内相对误差 $<1.7$ 倍），证明收发端共轭匹配滤波是消除 ISI 的必要条件——去掉匹配滤波（补 AGC）后同样 10 dB 的 BER 从 $1.84\times10^{-3}$ 恶化到 0.1123（61 倍）。
3. 滚降因子 $\beta$ 体现带宽效率与鲁棒性的折中：$\beta$ 从 0.15 增到 0.8，占用带宽增加 36%（$1.29\to1.76$ 倍符号率），换来残余 ISI 下降 53 倍、1/8 符号定时偏差下 BER 下降约 12 倍；工程上 $\beta=0.2\sim0.35$ 是兼顾两者的常用取值。
