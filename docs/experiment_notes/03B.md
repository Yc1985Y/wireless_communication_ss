# 03B 发送分集与空时分组码

## 实验目的

在平坦瑞利衰落信道下实现并验证 Alamouti 空时分组码（G2）与三发射天线正交空时码（G3），
定量比较 1×1 SISO、2×1、3×1、2×2 四种方案的分集阶数与分集增益，说明「发射分集如何在不占用接收天线的情况下把误码率曲线的斜率抬高」。
进一步在 QPSK 下对照发送分集（2×1 Alamouti）与接收分集（1×2 MRC），区分「分集阶数」与「阵列增益」两个不同的收益来源。

## 方法与参数

- **信道与信号**：BPSK 映射 0→+1、1→−1；准静态平坦瑞利衰落，每个码字独立抽取一次复高斯信道 h~CN(0,1)，接收端已知信道（相干检测）。
- **空时码**：G2 码字矩阵 [[x1,x2],[−x2\*,x1\*]]，每根天线除以 √2 保持总功率为 1；G3 采用 8 时隙×3 天线正交结构（前 4 时隙为符号本身、后 4 时隙为共轭），8 个时隙传 4 个符号，码率 R=1/2，每根天线除以 √3。
- **译码**：利用码字矩阵列正交性把 MIMO 检测化为标量检测，2×1 为 x1=(h1\*r1+h2r2\*)/[(1/√2)(|h1|²+|h2|²)]、x2=(h2\*r1−h1r2\*)/[(1/√2)(|h1|²+|h2|²)]；2×2 为两根接收天线各自解耦后按信道模平方加权同相合并；G3 按 8 时隙的相关组合译出 4 个符号。归一化因子 (2/√3)Σ|h|² 是幅度因子，去掉它只能判符号、不能得到等效信噪比。
- **Eb/N0 标定（关键）**：复噪声总方差记 W，合并后等效瞬时信噪比 γ 决定 Pb=Q(√(2γ))。按每比特发射能量归一时：1×1 与 2×1 取 W=1/γ̄（E[γ]=γ̄，分集阶数 2、无阵列增益）；G3 因半速率取 W=2/γ̄（半速率的 3 dB 损失被 Eb 定义吸收，E[γ]=γ̄）；2×2 取 W=1/γ̄（E[γ]=2γ̄，即 3.01 dB 阵列增益）。
- **理论基准**：BPSK-AWGN Pb=½erfc(√γ)；1×1 瑞利 Pb=½(1−√(γ̄/(1+γ̄)))；L 阶 MRC 用闭式解 Pb=((1−u)/2)^L Σ_{k=0}^{L−1}C(L−1+k,k)((1+u)/2)^k，u=√(μ/(1+μ))，μ 为每支路平均信噪比；同一式用 scipy.integrate.quad 对 χ² 分布数值积分交叉校验（两者相对偏差 4.7×10⁻¹⁴）。
- **仿真规模**：每点 2.56×10⁶ 比特（20000 块×16 比特×8 次重复），固定 torch/numpy/sionna 种子 42，两次运行 CSV 的 sha256 完全一致。

| 参数 | 取值 |
| --- | --- |
| 调制 | BPSK（拓展：QPSK，格雷映射） |

## 分析

四种方案的误码率曲线斜率随分集阶数单调增大，这与理论完全一致：1×1 SISO 的 BER 只随 γ̄ 缓慢下降，2×1 把两条独立信道的 |h|² 相加，等效信噪比服从 2 阶 Gamma 分布，深衰落概率从 ~1/γ 降到 ~1/γ²，因此斜率翻倍。实测高信噪比窗口的局部斜率为 1.01/2.25/2.94/3.28（理论同窗口 1.00/1.98/2.88/3.39）；除 2×1 的 2.25 因窗口内只剩 199/25 个误码而略高于 2（斜率的约 1$\sigma$ 标准误约 0.5）、3.28 略低于 4 之外，各方案在统计误差内与 1/2/3/4 的极限一致，原因是这些窗口的信噪比（8~24 dB）还不足以让曲线进入纯渐进区；二者逐点吻合说明斜率差异来自有限信噪比而非实现误差。定量的分集增益：以 BER=10⁻³ 为例，2×1 相对 SISO 节省 9.86 dB，3×1 G3 节省 12.64 dB，2×2 节省 16.92 dB；在 BER=10⁻² 处分别节省 5.38、6.91、10.63 dB。分集增益随阶数增长但不是线性的，因为 L 阶分集的 BER 渐进式是 ~(1/γ)^L 的常数因子乘以 γ^-L，L 每增加 1，同 BER 下所需信噪比按「dB 数 / L」的规律下降：从 BER=10⁻³ 的 9.86 dB（L=2，单阶约 4.9 dB）、12.64 dB（L=3，单阶约 4.2 dB）到 16.92 dB（L=4 且含 3.01 dB 阵列增益，单阶约 4.2 dB）。这里不能用 $10\lg(1/L!)$ 之类的固定因子来核对：L 阶瑞利分集的渐近式是 $P_b\approx c_L\bar{\gamma}_b^{-L}$$，$c_L=C(2L-1,L)/4^L$（$c_1\!=$ 0.25、0.1875、0.15625、0.1367$），同目标 BER 下所需信噪比的降幅是 $10[\lg(c_1/t)-(\lg(c_L/t))/L]$$，随目标 BER 变化（1e-2 时分别为 5.38/6.91/10.63 dB，1e-3 时为 9.86/12.64/16.92 dB，与实测逐点一致），只有当 $\bar{\gamma}_b\gg 1$ 时才退化为常数 $10\lg(c_1/c_L^{1/L})$$。本实验在 1e-2 处 1×4 的每支路信噪比只有 0.2 dB，并不满足该渐近条件，因此“每阶固定 4.2 dB”只是观察到的经验值而不是可套用的公式。G3 的公平性在于它是半速率码：若按「每信道符号」而非「每比特」衡量，它要多付 3 dB；本实验按 Eb/N0 归一后这 3 dB 已被吸收，所以 20 dB 处 G3（3.906e-6）反而优于 2×1（7.773e-5），体现 3 阶分集的斜率优势。拓展实验把「分集阶数」与「阵列增益」分离得很干净：2×1 Alamouti 与 1×2 MRC 的分集阶数同为 2，两条 BER 曲线斜率相同、彼此只差一个水平平移，实测平移量 3.02/3.02/3.00 dB 与理论 3.01 dB 相差 0.01~0.02 dB（约 0.3%~0.7%）；物理来源是 2×1 在发射端把功率分给两根天线（每根 1/√2），合并后总信噪比不增加，而 1×2 MRC 用两根接收天线各收一份全功率信号并按 MRC 加权合并，等效信噪比期望翻倍，故多出 3 dB 阵列增益——这正是「发射分集买分集阶数、接收分集同时买分集阶数与阵列增益」的区别。

## 结论

Alamouti G2（2×1、2×2）与 G3（3×1，R=1/2）在平坦瑞利信道下分别实现了 2、4、3 阶全分集，误码率曲线斜率与理论一致、增益分别为 9.86、16.92、12.64 dB（BER=10⁻³，相对 SISO）。
QPSK 下 2×1 发送分集与 1×2 接收分集分集阶数相同（斜率一致），后者多获得 3.01 dB 阵列增益，实验测得 3.02/3.02/3.00 dB。
