# 03E 实测水声信道上的 MC-BFSK 与水印传输

## 实验目的

1. 实现多载波二进制频移键控（MC-BFSK）的调制与非相干解调：194 个音调按"奇偶配对"承载 97 bit/帧，接收端用与调制窗一致的复相关做能量检测，验证纯净基带链路可实现零误码。
2. 基于 Watermark 项目公开的水声实测信道数据集（NOF1_001~004，时变冲激响应 $h(t,\tau)$，258 个时间快照 × 2048 个时延抽头），实现时变多径信道的"回放滤波"（replay filter），把仿真波形真实地"过"一遍海上实测信道。
3. 定量评估实测水声信道相对理想 AWGN 链路的代价：多径时延统计、接收/发射功率比、无噪声回放误码、BER-信噪比曲线与发射功率扫描，并给出 MC-BFSK 在频率选择性衰落下的鲁棒性解释。

## 方法与参数

**MC-BFSK 的时频结构。** 一个超帧承载 $M/2=97$ bit，第 $m'$ 个比特决定激活第 $2m'+1$ 或第 $2m'+2$ 个音调（二进制下标 $0,\dots,193$）。音调频率为

$$
f_m=f_c+\Delta f\left(m-\frac{M-1}{2}\right),\qquad m=0,\dots,M-1,
$$

即带宽 $M\Delta f=194\times29\ \mathrm{Hz}\approx5.63\ \mathrm{kHz}$，中心 $f_c=14$ kHz。为避免音调在时域重叠，每对音调的起始时刻由 `tone_time_offsets` 给出：偶数音调在 $m'\Delta t$，奇数音调在前半帧或后半帧（$m'\le M/4$ 时加 $T_{sf}/2$，否则减 $T_{sf}/2$），其中 $\Delta t=\lfloor 2T_{sf}f_s/M\rfloor/f_s\approx1.93$ ms。发射波形为各音调加 Hann 窗后叠加：

$$
x(t)=\sum_{m'=0}^{M/2-1} w(t-t_{m'})\cos\!\big[2\pi f_{m'}t+\varphi_{m'}\big],
$$

$w(\cdot)$ 为长度 $T_w=0.164$ s 的 Hann 窗，$\varphi$ 为随机初相。

**非相干能量检测。** 接收端先下变频到复基带 $r_{bb}(t)=2r(t)e^{-\mathrm{j}2\pi f_ct}$，再对每个音调在**与调制相同的时间窗**内做复相关：

$$
E_m=\Big|\sum_{n} r_{bb}[n]\,w[n]\,e^{-\mathrm{j}2\pi(f_m-f_c)n/f_s}\Big|^2,
$$

判决 $\hat b_{m'}=\mathbb{1}[E_{2m'+1}>E_{2m'}]$。该检测器只用能量、不用相位，因此对多径引起的载波相位旋转与信道时变天然免疫，代价是约 3 dB 的相干检测损失。

**Watermark 实测信道回放。** `.mat` 文件含 $h\in\mathbb{C}^{258\times2048}$（快照率 $f_{st}=7.8125$ Hz，时延轴采样率 $f_{s\tau}=16$ kHz）、$f_c=14000$、$V_0=0.0625$。回放滤波分三步：

1. 下变频与重采样：$x_{bb}[n]=x[n]e^{-\mathrm{j}2\pi f_c n/f_s}$（$f_s=96$ kHz），再用 `resample_poly(x_bb,1,6)` 降到 $f_{s\tau}=16$ kHz——该 1/6 抗混叠低通同时滤掉 $-2f_c$ 镜像；
2. 时变 FIR：$y[n]=\sum_{\tau}h(t_n,\tau)x_{bb}[n-\tau]$，$t_n=n/f_{s\tau}$，$h(t_n,\cdot)$ 由相邻两个快照按 $t_nf_{st}$ 线性插值得到。实现上按 $f_{s\tau}/f_{st}=2048$ 个样点分块（恰好等于抽头数 $L=2048$），块内用 `fftconvolve` 与前后两个快照分别卷积，再按块内线性 ramp 组合，等效于逐样点插值，但只需 2 次 FFT/块（20 帧整段 0.26 s）；
3. 搬回载频：`resample_poly(y,6,1)` 回到 96 kHz 后取 $2\,\Re\{y\,e^{\mathrm{j}2\pi f_c n/f_s}\}$（因子 2 补偿实信号→复基带的 ½ 幅度）。

信道矩阵按每行能量归一化（原始 $h$ 含测量系统增益，平均功率约 $1.03\times10^6$）：$h\leftarrow h/\sqrt{\overline{\sum_\tau|h|^2}}$，使回放链路只保留多径结构、不引入额外增益。

**噪声与信噪比定义。** 噪声在 96 kHz 采样带宽内按发射功率标定：$P_n=\overline{x^2}/10^{\mathrm{SNR}/10}$，即横轴为相对发射功率的等效信噪比。由于实测回放输出功率是发射功率的 1.94~2.30 倍，接收端实际信噪比还要高 2.9~3.6 dB。

| 参数 | 取值 |

## 分析

纯净链路 20 帧 1940 bit 全部正确，说明 194 音调的正交性、Hann 窗与能量检测实现无误；NOF1_001 回放同样 0 误码，此时四信道时延扩展已达 1.81~2.50 ms、重心时延 3.58~4.09 ms（离散度 0.52 ms），仍未被非相干检测"看见"。原因有二：其一，符号内多径表现为音调幅度与相位的慢变化，能量检测对相位不敏感，只损失约 $1-\eta$ 的相关能量；其二，$\Delta f=29$ Hz 配合 $T_w=0.164$ s 使音调间串扰很低，毫秒级时延展宽只等效于频域数百赫兹量级的幅度起伏。

加入噪声后曲线分成两段。低信噪比区（$-24\sim-16$ dB）四条实测信道反而略优于纯净链路（$-20$ dB：0.170~0.184 对 0.202），因为回放输出功率是发射功率的 1.94~2.30 倍（$+2.9\sim3.6$ dB）。高信噪比区曲线反转：$-12$ dB 处纯净链路 BER 已降到 $1.55\times10^{-3}$，而四条实测信道仍在 $2.7\times10^{-2}\sim4.1\times10^{-2}$，相差 18~27 倍；以 BER $=10^{-2}$ 为门限，纯净链路需约 $-14.1$ dB，四条实测信道分别需 $-6.7/-4.2/-7.3/-6.9$ dB，即多付出 6.8~9.9 dB。这一代价不是平均功率损失（回放功率反而更大），而是**频率选择性造成的子载波衰落**：194 个音调中部分落入 14 kHz 附近的深衰落（中心处幅度仅 0.310），其能量被噪声淹没。信道时变与残余多径使高 SNR 段仍有零星误码（8~12 dB 每条曲线 0~3 个），但曲线没有出现水平平台：12 dB 的四个值均 $\le5.2\times10^{-4}$，其中两条已归零。四信道曲线相互交织（1940 bit 上仅差 2~8 个误码），统计上不足以区分优劣，只能给出"同批次信道特性相近"的结论。表 4 则从另一侧确认链路可用性：固定噪声下发射幅度提高 18 dB，BER 从 $1.19\times10^{-1}$ 单调降到 $3.09\times10^{-3}$。

## 结论

1. MC-BFSK + Hann 窗 + 复相关能量检测在纯净链路与 Watermark 实测信道（时延扩展 1.81~2.50 ms、快照率 7.8125 Hz）上均实现零误码回放：20 帧 1940 bit 全部正确，验证了非相干多载波体制对水声多径与时变的鲁棒性，也验证了回放滤波（2048 抽头分块 + 快照线性插值）的正确性。
2. 频率选择性衰落是主要代价：达到 BER $=10^{-2}$ 时实测信道比理想 AWGN 链路多需 6.8~9.9 dB 信噪比，8~12 dB 处仅剩 0~3 个误码、没有形成误码平台；该代价来自部分音调落入深衰落（14 kHz 处幅度 0.310），而非平均功率损失。
3. 工程上可行的补偿方向是频域分集（交织/重复编码）与自适应功率分配；本文的时变回放滤波为后续 OFDM/扩频体制的实测信道验证提供了可直接复用的仿真接口。
