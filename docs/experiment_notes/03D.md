# 03D 多天线接收分集（16-QAM MRC / SC）

## 实验目的

在 16-QAM 平坦瑞利衰落链路上实现接收端最大比合并（MRC）与选择合并（SC），定量区分天线阵列带来的**阵列增益**与多支路独立衰落带来的**分集增益**。用 1×1 / 1×2 / 1×4 三档天线数对比两种合并准则的符号错误率（SER），再用 BPSK 支路与 Proakis 闭式解、16-QAM 支路与半解析理论曲线互相校验，确认"多天线同时降低误码率并加陡曲线斜率"这一结论可以被精确测量和预测。

## 方法与参数

**链路**：随机比特 → Gray 映射 16-QAM（星座点 $(\pm1,\pm3)/\sqrt{10}$，$E_s=1$，最小欧氏距离 $d_{\min}=2/\sqrt{10}$）→ 平坦瑞利信道 $h_i\sim\mathcal{CN}(0,1)$（逐符号独立）→ $r_i=h_i s+n_i$，$n_i\sim\mathcal{CN}(0,N_0)$ → 接收端合并 → 最小欧氏距离逐符号判决。噪声按 $N_0=1/\gamma_s$ 设定（$\gamma_s=E_s/N_0$，接收天线数 $L$ 不影响总发射能量）。

**两种合并准则**

- MRC：$y=\sum_{i=1}^{L}h_i^{*}r_i\big/\sum_{i=1}^{L}|h_i|^2$，等价于按信噪比加权，合并后等效 SNR 为 $\sum_i|h_i|^2\gamma_s$；
- SC：只取 $|h_i|$ 最大的一路，等效 SNR 为 $\max_i|h_i|^2\gamma_s$。

**理论对照**：16-QAM 的 AWGN 符号错误率 $P_s^{\rm AWGN}(\gamma)=1-\big[1-\tfrac32Q(\sqrt{\gamma/5})\big]^2$；衰落平均 SER 由 $\gamma_s$ 的分布半解析求出——MRC 用 $\Gamma(L,1)$ 分布、SC 用 $\max_{i\le L}|h_i|^2$ 的分布（$F(x)=(1-e^{-x})^L$）对 $P_s^{\rm AWGN}$ 做数值积分。BPSK 支路直接用 Proakis 闭式解 $P_b=\big(\tfrac{1-\mu}{2}\big)^L\sum_{k=0}^{L-1}\binom{L-1+k}{k}\big(\tfrac{1+\mu}{2}\big)^k$，$\mu=\sqrt{\bar\gamma_b/(1+\bar\gamma_b)}$，$\bar\gamma_b=2\bar\gamma_s$。

**仿真参数**

| 项目 | 16-QAM 主实验 | BPSK 拓展实验 |
| --- | --- | --- |
| 调制 / 归一化 | 16-QAM，$(\pm1,\pm3)/\sqrt{10}$，$E_s=1$ | BPSK，$E_s=1$ |
| 合并方式 / 天线数 | MRC 与 SC，$L=1,2,4$ | MRC，$L=1,2,4$ |
| 每点样本数 | 1000 块 × 100 符号 = $10^5$ 符号 | 2000 块 × 100 bit = $2\times10^5$ bit |

| SNR 网格 | $E_s/N_0$ = 0~30 dB，步长 3 dB（11 点） | $E_b/N_0$ = 0~20 dB，步长 2 dB（11 点） |
| 判决 | 逐符号最小欧氏距离 | 逐比特符号判决 |

**评价指标**：SER=10⁻²、10⁻³ 处所需 $E_s/N_0$（对数域线性内插）、相对 1×1 的 dB 增益、用 SER 曲线斜率估计的实测分集阶数（每 10 dB 下降一个数量级记 1 阶）。

**横轴口径说明**：本实验模板与讲义的 SER 横轴按**每符号信噪比** $E_s/N_0$ 标注，而本报告其他章节（01/02/03A 的 BER 曲线、03H 的检测器对比）多用**每比特信噪比** $E_b/N_0$。二者相差 $\log_2 M$ dB：16-QAM 有 $E_s/N_0 = E_b/N_0 + 10\log_{10}4 = E_b/N_0 + 6.02$ dB，BPSK 两者相等。因此后文 1×4 MRC 与无衰落 AWGN 曲线的交叉点 19.34 dB（$E_s/N_0$）折合 $E_b/N_0 = 13.3$ dB，与其他章节曲线横向比较时须按此换算。

## 分析

分集增益与阵列增益在数据上可以清楚分开：以 SER=10⁻² 为基准，1×1 需要 28.11 dB 的 $E_s/N_0$，1×2 MRC 只需 18.11 dB（省 10.00 dB），1×4 MRC 只需 12.03 dB（省 16.07 dB）。1×4 MRC 的 16.07 dB 由两部分构成——4 支路相干合并的阵列增益 $10\lg4=6.02$ dB，以及把 4 个独立瑞利支路"取和"带来的分集增益（约 10 dB）。低信噪比区间 1×4 MRC 一直优于无衰落 AWGN 基准：$E_s/N_0$ = 0 dB 处两者 SER 为 4.98×10⁻¹ 对 7.41×10⁻¹，直到 19.34 dB 才被反超（无衰落 AWGN 按指数下降，而 4 阶分集只是多项式下降），1×2 MRC 的交叉点提前到 13.11 dB；换算成 $E_b/N_0$ 标注（16-QAM 相差 6.02 dB）两者分别落在 13.3 dB 与 7.1 dB，定量印证了讲义"多天线接收分集在低信噪比可优于单天线无衰落基准"的判断。两种合并准则的差距随天线数扩大：SER=10⁻³ 处 MRC 相对 SC 领先 1.91 dB（2 天线）与 3.23 dB（4 天线），因为 SC 只利用最好的一路、丢弃其余支路能量，其等效 SNR 的均值增长远慢于 MRC 的和。实测分集阶数 1.97（1×2 MRC）、2.91（1×4 MRC）、1.82（1×2 SC）、2.80（1×4 SC）与理论值 $L$ 基本吻合；逐项看，1×2 MRC 的 1.97 略**高于**同一窗口下稠密理论曲线的 1.83（这是 3 dB 网格、窄拟合窗口带来的涨落），1×4 MRC 的 2.91 接近理论 2.92（24 dB 起落入零误码平台，可用于拟合的点变少），两条 SC 曲线的 1.82/2.80 与理论 1.80/2.85 也在同一量级——即分集阶数的偏差都可由网格密度与误码分辨率解释，不需要引入实现误差。仿真与半解析理论的最大相对偏差为 MRC 的 2.96%/3.29%/5.43%（$L$=1/2/4）与 SC 的 3.92%/2.22%（$L$=2/4），全部落在 $10^5$ 符号的蒙特卡洛抖动范围内；BPSK 支路与 Proakis 闭式解在 0~20 dB 的最大绝对偏差仅 $8.5\times10^{-4}$，说明合并与判决实现无误、噪声口径（$N_0=1/\gamma_s$）与理论一致。

## 结论

接收分集同时兑现阵列增益与分集增益：1×4 MRC 相比 1×1 在 SER=10⁻² 处节省 16.07 dB、实测分集阶数 2.91，且在 SER=10⁻³ 处比 SC 领先约 3.3 dB（2 天线约 1.5 dB；该差值由 3 dB 网格仿真曲线内插得到，用 0.5 dB 网格的半解析理论反解为 3.34 dB 与 1.50 dB，故此处按 ±0.3 dB 精度理解）；16-QAM 仿真与半解析理论偏差小于 6%，BPSK 与 Proakis 闭式解偏差小于 $1\times10^{-3}$，验证了实现与理论口径的一致性。
