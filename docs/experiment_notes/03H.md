# 03H 2×2 平坦衰落 MIMO 的 LMMSE 检测

## 实验目的

在 2×2 空间复用链路上实现最小均方误差（LMMSE）检测器 $\hat{x}=(H^{\mathrm{H}}H+\sigma^2I)^{-1}H^{\mathrm{H}}y$，并与迫零（ZF）检测、最大似然（ML）穷举对比，定量回答三个问题：正则化项 $\sigma^2I$ 在低信噪比究竟能换回多少 dB；高信噪比下 LMMSE 是否会退化为 ZF、两条线性检测曲线为何保持平行；以及线性检测与 ML 之间"丢失的分集阶数"如何体现在 BER 曲线上。主实验用 Sionna 的 `FlatFadingChannel` + `lmmse_equalizer` 完成模板要求的 BER 曲线，补充实验用自实现检测器同时给出 ZF/LMMSE/ML 三条曲线并做交叉校验，再把结论扩展到 16-QAM。

## 方法与参数

**信号模型**：$y=Hx+n$，$H\in\mathbb{C}^{2\times2}$ 元素独立同分布 $\mathcal{CN}(0,1)$（$E\lvert h_{ij}
\rvert^2=1$，准静态、逐符号在 20 万次抽样上统计），$n\sim\mathcal{CN}(0,N_0I)$，$x$ 为 $E_s=1$ 的 QPSK 或 16-QAM 符号。两种调制下 $N_0=1/(10^{E_b/N_0/10}\cdot b)$，$b=2$（QPSK）或 $b=4$（16-QAM），即 $E_s/N_0=b\,E_b/N_0$；$N_0$ 是**每个接收天线**上的复噪声总方差。

**三种检测器**

- ZF：$W=(H^{\mathrm{H}}H)^{-1}H^{\mathrm{H}}$，硬判决前按 $\mathrm{diag}(WH)^{-1}$ 归一；
- LMMSE：$W=(H^{\mathrm{H}}H+N_0I)^{-1}H^{\mathrm{H}}$，同样按 $\mathrm{diag}(WH)^{-1}$ 消除偏置（Sionna `lmmse_equalizer` 的 `no_eff` 即该等价噪声方差）；
- ML：$\hat{x}=\arg\min_{\tilde{x}\in\mathcal{X}^2}\|y-H\tilde{x}\|^2$，QPSK 16 个候选、16-QAM 256 个候选全穷举，作为性能上界。

**实验设置**

| 项目 | 模板主实验 | 检测器对比实验 |
| --- | --- | --- |
| 天线配置 | 2 发 2 收（`FlatFadingChannel`） | 2 发 2 收（同分布自实现信道） |
| 调制 | QPSK，$b=2$ | QPSK（$b=2$）与 16-QAM Gray（$b=4$） |
| 检测器 | Sionna `lmmse_equalizer` + APP Demapper | 自实现 ZF / LMMSE / ML + 逐比特硬判决 |
| 每点比特数 | 10 帧 × 2048 组 × 4 bit ≈ $8.2\times10^4$ | 3 帧 × 80000 组 × 4 bit ≈ $9.6\times10^5$（16-QAM 为 3×40000×8） |
| Eb/N0 网格 | 0, 3, …, 12 dB（5 点） | QPSK 0~22 dB、16-QAM 0~24 dB，步长 2 dB |
| 随机种子 | torch / numpy / sionna 均 42 | 同左 |
| 交叉校验 | — | 自实现 LMMSE 与 Sionna 的硬判决比特一致率 100.000% |

**1×1 SISO 参考线**：瑞利衰落 + QPSK 的闭式 $P_b=\frac12\left[1-\sqrt{\bar\gamma_b/(1+\bar\gamma_b)}\right]$，其中 $\bar\gamma_b=E_b/N_0$ 是**平均比特**信噪比（对 QPSK 有 $E_s/N_0=2E_b/N_0$，但闭式里的 $\bar\gamma$ 必须取 $E_b/N_0$；取错会在参考线上引入 3.01 dB 的乐观偏差）。

**信道模型自检**（20 万次抽样）：$E\lvert h
\rvert^2=0.9984$（理论 1.0），接收端残差方差 0.04980（理论 $N_0=0.05$），条件数 $20\lg\kappa(H)$ 中位数 9.43 dB、90% 分位 17.53 dB、最大值 60.16 dB。

## 分析

正则化的收益集中在低信噪比：QPSK 在 0 dB 处 ZF 的 BER 为 $1.465\times10^{-1}$，LMMSE 降到 $1.059\times10^{-1}$（相对低 27.7%），6 dB 时差距仍有 31.4%；以 BER=10⁻² 为判据，ZF 需要 13.93 dB，LMMSE 只需 12.07 dB（省 1.86 dB），ML 只需 6.94 dB（相对 LMMSE 再省 5.13 dB）。但高信噪比处两条线性检测曲线保持平行：实测分集阶数 ZF 0.97、LMMSE 0.98，都只有约 1 阶，说明 LMMSE 换回的是固定的正则化增益，而不是分集增益——$N_0\to0$ 时 $N_0I$ 相对 $H^{\mathrm{H}}H$ 可忽略，LMMSE 退化为 ZF，两条曲线间距收敛到 1.86 dB；16-QAM 因工作点更高（$N_0$ 更小）、噪声放大本就不显著，ZF 与 LMMSE 只差 0.65 dB。ML 穷举的斜率明显更陡（1.88~1.91 阶），16-QAM 在 18 dB 处 BER 比 LMMSE 低 88.7%，因为它同时利用了 2 个数据流上的全部信息，兑现了空间复用链路的第 2 阶分集。

把三条曲线与 1×1 SISO 瑞利 + QPSK 的闭式理论（13.85 dB）对齐，可以看到空间复用的真实代价与收益：**ZF 需要 13.93 dB，比 SISO 还差 0.08 dB**——2 发 2 收虽多了一根接收天线，但迫零为消除一个流间干扰消耗掉了这份阵列增益，净效果与 SISO 持平，这正是 ZF 分集阶数只有 1 的原因；**LMMSE 反而比 SISO 好 1.78 dB**，来自 $N_0I$ 正则化对深衰落子信道的抑制（等价于对弱特征模的收缩）；**ML 好 6.91 dB**，是唯一逼近 2 阶分集的检测器。因此"空间复用只有用 ML 才能兑现分集增益"的数据表述应精确为：线性检测中 LMMSE 只剩 1.78 dB 的固定正则化增益，ZF 几乎完全被流间干扰抵消，仅 ML 通过联合检测把 2 阶分集全部拿到（这也是工程上 ML/LMMSE 折中方案存在的原因）。信道条件数中位数 9.43 dB、90% 分位 17.53 dB 表明相当比例的 $H$ 接近奇异，这正是 ZF 在低 SNR 把噪声放大的根源；信道自检给出的 $E\lvert h
\rvert^2=0.9984$、残差方差 0.04980（对 $N_0=0.05$）证明模型与噪声口径无误。

## 结论

LMMSE 以 $N_0I$ 正则化抑制 ZF 的噪声放大，在 BER=10⁻² 处比 ZF 省 1.86 dB，但两条线性检测曲线斜率同为约 1 阶、高 SNR 处只留下固定间距；ML 穷举达到 1.88~1.91 阶分集、相对 LMMSE 再省 5.13 dB（16-QAM 为 4.35 dB），与理论一致，自实现 LMMSE 与 Sionna `lmmse_equalizer` 的硬判决比特一致率为 100%。与 1×1 SISO 瑞利 QPSK 的闭式理论（13.85 dB）相比，2×2 ZF 差 0.08 dB、LMMSE 好 1.78 dB、ML 好 6.91 dB：空间复用链路的分集增益只有 ML 能完整兑现，线性检测仅能通过正则化换回不到 2 dB 的固定增益。
